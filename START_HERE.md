# Start here

1. Open `assignments/README.md` for the full investigation brief.

2. Start Pi with `pi`.

3. **Task 1** (~15 min) — paste this into Pi:

   ```
   Follow the instructions in assignments/a-mediterranean-trap/assignment-part-1.md.
   Save the final HTML report in ~/output.
   ```

4. **Task 2** — when Task 1 is done, paste this into Pi:

   ```
   Follow the instructions in assignments/a-mediterranean-trap/assignment-part-2.md.
   Add the new findings to the existing HTML report in ~/output.
   ```

5. Open your report at `https://<your-vm>/output/<filename>.html`, or the URL Pi prints for live apps.
